# SCAF v0.2.0rc11 Review Instructions

## Scope

Review the Evidence-Driven Engineering Pattern Candidate Semantic
Foundation.

## Required Checks

1.  Verify the pattern remains domain-neutral.
2.  Verify no specific company product, customer system, internal
    product name, or proprietary identifier is included.
3.  Verify separation:

SCAF: - engineering principles and reusable patterns

Implementation Framework: - concrete evidence capture, retention, and
export mechanisms

Specific System Application: - downstream realization

4.  Verify Evidence model:

-   Source Evidence
-   Change Evidence
-   Runtime Evidence
-   Probe Evidence

5.  Verify Probe and Diagnostic lifecycle separation.

6.  Verify AI assistance does not introduce engineering authority.

7.  Verify no:

-   authority registry migration
-   Project Application migration
-   EPP migration
-   L4 expansion
-   code generation
-   generic instrumentation CI

## Output

Create:

SCAF_v0.2.0rc11_Review.md

Include: - Overall Verdict - Findings - Boundary Verification - Scope
Verification - Gate Decision
