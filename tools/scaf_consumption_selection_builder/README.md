# SCAF Consumption Selection Builder

`tools/scaf_consumption_selection_builder` deterministically constructs the accepted
v0.0.7rc03 Consumption Selection YAML representation from one exact validated
Effective Project Profile and explicit bounded selection inputs.

The builder validates the selected Effective Project Profile before consuming its
state, constructs only the accepted bounded state/authority predicate plus exact
caller-declared omission set, and self-validates generated bytes through the accepted
v0.0.7rc05 source-aware Consumption Selection validator before return/emission.

Production CLI:

```text
python -m tools.scaf_consumption_selection_builder.builder \
  --purpose "Illustrative bounded context-selection example over three exact PAO identities." \
  --state applicable \
  --state no_current_disposition \
  --authority-mode explicit_set \
  --authority-id SCAF-AK-001 \
  --authority-id SCAF-AK-002 \
  --authority-id SCAF-AK-003 \
  --omit-authority-id SCAF-AK-003 \
  --omission-basis "Illustrative entry-count bound includes two of three predicate-eligible entries."
```

Successful stdout is canonical YAML only. Errors are emitted on stderr.

This builder performs no scope resolution, applicability inference, ranking, token-budget
calculation, Pattern selection, context-source resolution, AI orchestration, engineering
approval, verification/compliance determination, release decision, or closure decision.
