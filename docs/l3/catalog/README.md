# L3 Catalog Placement

v0.0.3rc03 introduces the first seven published SCAF L3 Pattern / Mechanism entries after the v0.0.3rc02 catalog-contract closure gate passed.

Family paths are:

```text
catalog/SUP/
catalog/COM/
catalog/REC/
catalog/FTL/
catalog/TIM/
catalog/PST/
catalog/LCM/
catalog/EVD/
catalog/SYN/
catalog/SEC/
```

Only families with current entries require committed directories. Pattern identity is based on the immutable primary mechanism family after publication. Cross-concern coverage belongs in pattern metadata through L2 trace relations rather than by duplicating the same pattern under multiple family paths.

All v0.0.3rc03 entries are `Candidate / M1`; publication of the ID does not imply `Available` status, project selection or L2 satisfaction.
