# L3 Catalog Placement

v0.0.3rc05 carries forward the same seven published SCAF L3 Pattern / Mechanism entries after the successful rc04 trace-closure review and records their maturity advancement to M2 while retaining Candidate status.

Family paths are:

```text
catalog/SUP/
catalog/COM/
catalog/REC/
catalog/FTL/
catalog/TIM/
catalog/PST/
catalog/LCM/
catalog/EVD/
catalog/SYN/
catalog/SEC/
```

Only families with current entries require committed directories. Pattern identity is based on the immutable primary mechanism family after publication. Cross-concern coverage belongs in pattern metadata through L2 trace relations rather than by duplicating the same pattern under multiple family paths.

All seven entries are `Candidate / M2` in v0.0.3rc05. M2 records completed architecture review; it does not imply `Available` status, project selection, recommendation or L2 satisfaction.
