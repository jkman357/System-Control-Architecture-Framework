# L3 Catalog Placement

v0.0.3rc06 carries forward the same seven published SCAF L3 Pattern / Mechanism entries and records their explicit catalog acceptance after the rc05 lifecycle review validated all seven M2 states and judged all seven ready for availability.

Family paths are:

```text
catalog/SUP/
catalog/COM/
catalog/REC/
catalog/FTL/
catalog/TIM/
catalog/PST/
catalog/LCM/
catalog/EVD/
catalog/SYN/
catalog/SEC/
```

Only families with current entries require committed directories. Pattern identity is based on the immutable primary mechanism family after publication. Cross-concern coverage belongs in pattern metadata through L2 trace relations rather than by duplicating the same pattern under multiple family paths.

All seven entries are `Available / M2` in v0.0.3rc06. `Available` means accepted for project consideration under the current catalog release; it does not imply project applicability, selection, recommendation, compliance, verification or L2 satisfaction. M2 remains the independent architecture-review maturity state.
