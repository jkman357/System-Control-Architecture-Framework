# Evidence-Driven Engineering Pattern Terminology Alignment

## v0.2.0rc13

## Purpose

Clarify evidence taxonomy terminology while preserving existing SCAF
layering and Pattern identity.

## Evidence Categories

### Source Evidence

Evidence describing the implemented source baseline.

### Change Evidence

Evidence describing modifications between versions or revisions.

### Runtime Evidence

Evidence collected from system execution behavior.

### Compare Evidence

Evidence generated by comparison against:
- expected behavior;
- previous baseline;
- alternative implementation results.

## Relationship with Probe Evidence

Probe Evidence represents an observability collection mechanism.

Probe Evidence is not equivalent to Compare Evidence.

Relationship:

Probe Evidence
    |
    v
Runtime Evidence collection

Compare Evidence
    |
    v
Baseline and result comparison

The terminology separation preserves observability lifecycle concepts
while maintaining evidence classification clarity.
