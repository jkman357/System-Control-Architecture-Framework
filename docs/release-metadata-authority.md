# Release Metadata Authority

## Purpose

Define ownership of SCAF release identity information.

## Classification

| Type | Ownership |
| --- | --- |
| Normative release metadata | Canonical release metadata authority |
| Generated metadata | Tool output only |
| Historical record | CHANGELOG / release history |
| Review material | Review directory |

## Authority Rule

A release identity must have one authoritative source to prevent conflicting status declarations.
